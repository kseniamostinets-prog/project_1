# Калькулятор чаевых

Небольшой калькулятор чаевых: считает сумму чаевых, итоговую сумму счёта и сумму на человека.

## Как пользоваться
1. Введите сумму счёта
2. Укажите процент чаевых
3. Укажите количество людей
4. Нажмите «Посчитать»

## Технологии
- HTML
- CSS
- JavaScript

## Запуск
Откройте `index.html` в браузере.
